Label guide

Topics: access (login/account); usability (controls/navigation/ads/playlists); playback (failures/crashes/lag); downloads (offline/saved music); catalog (content/search/recommendations/lyrics); billing (price/charges/paywalls/premium entitlement); support (support contact/response); other.

Intent precedence: cancellation → complaint → request → praise → unclear. Select the highest-severity specific problem, then the first mentioned on a tie. For praise, use the first specific feature.

Severity: 1 no problem/praise/unclear/pure request; 2 annoyance or generic criticism without supported functional loss; 3 degraded function with some use remaining; 4 clearly blocked core task; 5 explicit serious financial, privacy or data harm. Anger, price, stars and cancellation alone do not raise severity.

Sentiment: −1 strongly negative to +1 strongly positive, 0 neutral. Entities: JSON list of explicitly named features, or []. Evidence: exact text copied from the review. Needs review: true for ambiguity or missing context. Record why in notes. These are your labels, not confirmed truth.
