# Human labeling

Open worksheet.html in a browser. Label all 50 reviews yourself; no model predictions are included. Download your labels after each session and save the CSV here as golden_50_human_labels.csv. Keep this file out of classification prompts, tuning, routing, and model inputs. The unchanged source template remains under supplied/. Browser storage is a convenience, not a backup.

Fill every label field. Use [] for no entities and an exact source substring for evidence. Add human_notes for ambiguity. Human answers must be completed before the final evaluation. AI-generated suggestions must not be described as human labels.
